1. ARCHITECTURE -- DOMAIN-DRIVEN, ONE BACKEND, THREE FRONT DOORS
---------------------------------------------------------------------------

   Traders (Android)     Suppliers (web / tablet)    Supplier ERPs
   Expo app              Next.js portal               Integration API
          \                     |                        /
           \                    |                       /
         +---------------- CLOUDFLARE ----------------------+
         | DNS · TLS · DDoS · WAF · rate limits · bot rules |
         +---------------------------------------------------+
                                |
      +-------------------------+----------------------------+
      |  API  (Flask, /api/v1, domain-driven)                |
      |  public pages (own process): record checker,         |
      |    client sign-off, PayFast notification receiver    |
      +-------------------------+----------------------------+
                                |
          PostgreSQL (one schema per domain) · Cloudinary (media,
          malware-scanned) · PayFast · Mapbox · email service

  DOMAINS (bounded contexts)  -- backend/src/domains/<area>/<domain>/
    Each: api/ (thin routes) · services/ (rules) · repositories/ (DB)
          · models/ · schemas/ (validation). Routes validate -> call a
          service -> return the standard envelope. Every route pins a
          role.

    identity      accounts, email + Google sign-in, verification, PIN,
                  device keys, roles
    trade         business profile + tools, credit book, suppliers,
                  catalogue, cart, orders, payments (PayFast + cash)
    jobs          builder jobs, stages, agreed changes, sign-off links,
                  house records
    ledger        sealed events in; chains and signatures verified
    handshake     both halves of a Cash Handshake -> CONFIRMED or DISPUTE
    integrity     CHAIN_BREAK, CLOCK_SKEW (PHANTOM_SALES if time)
    reputation    the track record with plain reasons (never a credit
                  score, never locks a tool)
    share         share links, revoke, view log, public checker
    integration   supplier ERP API: API keys, product/stock push, order
                  webhooks
  SHARED (never depends on a domain): core (envelope, errors, base
    model, decorators), media (Cloudinary + malware scan), email,
    audit, queue, rate limiting, validation, notifications, geo.

  ENFORCED, NOT JUST WRITTEN: architecture tests read the code and fail
  the build if one domain reaches into another's internals, as our
  earlier codebase does. Cheap to add, and strong evidence for
  "Technical implementation".

  FROM OUR EARLIER CODEBASE (declared in REUSE.md, adapted, renamed):
    core/ (responses, exceptions, base_model, decorators), extensions
    pattern, rate limiter, email (with a fake provider for dev), audit,
    queue, validation, media (Cloudinary provider, upload intents,
    malware-scan webhook, orphan sweeps), PayFast provider + ITN
    handling, Mapbox geocoding provider, architecture-test pattern.
    Everything Akayza-specific is written fresh.

2. PRODUCTION SECURITY (on top of 06 section 8's SSDLC)
---------------------------------------------------------------------------

  CLOUDFLARE IN FRONT OF EVERYTHING PUBLIC
    - DNS, TLS certificates, unmetered DDoS protection, and the FREE
      managed WAF ruleset, all on the free plan.
    - Rate-limiting rules on sign-in, codes and the public pages; bot
      protection on the record and sign-off pages.
    - The origin accepts traffic ONLY from Cloudflare (firewall
      allow-list, or a Cloudflare Tunnel so the server has no open
      port at all).
    - Growth: the Pro plan ($20/month billed annually) adds the full
      managed WAF rules and image optimisation.

  MALWARE SCANNING ON EVERY UPLOAD (the pattern from our earlier code)
    - Uploads go to Cloudinary with the Perception Point malware-
      detection add-on turned on.
    - A new file starts as PENDING and is hidden. Cloudinary's webhook
      reports the scan result (average ~10 s). APPROVED -> visible;
      REJECTED -> deleted and logged. A sweep job clears uploads that
      never finish.
    - Covers supplier product photos, builders' stage photos and
      profile images.
    - A switch in config turns scanning off without a redeploy if the
      free tier runs out.

  DATA AND OPERATIONS
    - Secrets in environment variables only; per-service keys (a
      Akayza-only Cloudinary key); rotated after the event.
    - Daily database backups (included with managed PostgreSQL); a
      tested restore.
    - Error monitoring (Sentry free tier) with no personal data in
      events.
    - Audit log of security events (sign-ins, key changes, shares,
      disputes, payment status).
    - POPIA: data minimised; the owner controls sharing. For the pilot,
      hosting in the EU/US region is a cross-border transfer POPIA
      allows with adequate safeguards; for production we move to AWS
      Cape Town (af-south-1) so data stays in South Africa.

3. REAL RUNNING COSTS (researched 24 Sep 2026; $1 = R16.50)
---------------------------------------------------------------------------

  PILOT STAGE (first ~3 months, up to a few hundred traders)
    Hosting: DigitalOcean app server (~$12)          ~R200
    Managed PostgreSQL, daily backups ($15)          ~R250
    Cloudflare Free (DNS, TLS, DDoS, basic WAF)       R0
    Cloudinary Free (25 credits) + malware add-on
      free tier                                       R0
    Email: Resend Free (3,000/month, 100/day)         R0
    Mapbox free tier (50,000 map loads, 50,000
      static images, 100,000 directions a month)      R0
    PayFast: no monthly fee (per transaction only)    R0
    Error monitoring: Sentry free tier                R0
    Domain (.co.za ~R100/year)                        ~R10
    ----------------------------------------------------------
    PILOT TOTAL                                       ~R460 / month
    Once-off: Google Play developer account ($25)     ~R415

  GROWTH STAGE (thousands of traders, data kept in South Africa)
    AWS Cape Town app + managed PostgreSQL (est.)     ~R1,500
    Cloudflare Pro ($20, annual)                      ~R330
    Cloudinary Plus ($89 annual / $99 monthly)        ~R1,470-R1,630
    Malware scanning paid tier (price on quote)       TBC
    Resend Pro ($20, 50,000 emails)                   ~R330
    Sentry team plan                                  ~R430
    Mapbox pay-as-you-go beyond the free tier         R0-R500
    ----------------------------------------------------------
    GROWTH TOTAL                                      ~R4,000-R4,700 / month

  WHAT THIS MEANS FOR 06
    - 06 said running costs are ~R4,000/month: that's right for the
      GROWTH stage. The pilot runs on ~R500/month.
    - 06's "WhatsApp / SMS codes R1,500" line goes: sign-in is email +
      Google (free); WhatsApp codes are roadmap.
    - The pilot budget line "running costs R24,000" (R4,000 x 6) covers
      the move to growth hosting and paid tiers by month 3-4, with
      headroom. Keep R300,000 as the ask.
    - Break-even at growth stage (~R4,700): 4 suppliers on Pro. At
      pilot stage: 2 suppliers on Starter.
