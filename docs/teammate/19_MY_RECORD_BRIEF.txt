1. BACKEND: GET /me/record/summary?month=YYYY-MM
---------------------------------------------------------------------------

  Where: backend/src/domains/proof/ledger/ (the folders exist, empty).
    api/routes.py, schemas/record_schemas.py, services/record_service.py
    Import the routes in src/api/__init__.py (one line, like the others).

  Route: @auth_required(dashboard="informal_business"),
         @limiter.limit("30 per minute"), no body.
  month: strict YYYY-MM; default this month (SAST); not in the future;
         not before the account was created; anything else -> 422
         (2026-13, 2026-9, ../, 9999-01, empty, a list...).

  Build it by calling each tool's SERVICE -- never its repositories
  (tests/architecture/test_domain_boundaries.py must stay green):
    - orders:      commerce/orders/services/order_service
    - credit book: informal_trader/credit_book/services/credit_book_service
    - jobs:        informal_trader/jobs/services/jobs_service
  Today's service summaries are "all time" or "this month" only. Add a
  month-aware function in each (e.g. money_for_month(user, start, end))
  next to the existing summary():
    - credit book + jobs: your own features, go ahead.
    - orders (Mandla's): add ONE function money_summary_for(user, start,
      end) that reuses payment_evidence(); nothing else in orders
      changes. Say so in the PR.

  Answer (three blocks, NO grand total field anywhere):
    {
      "month": "2026-09",
      "orders": {                          # by ORDER date, only mine
        "provider_verified": {"cents", "orders"},   # paid in the app, PayFast-confirmed
        "confirmed_by_both": {"cents", "orders"},   # cash, both sides said so
        "not_confirmed":     {"cents", "orders"}    # cash, not confirmed
      },
      "credit_book": {"given_cents", "paid_back_cents"} | null (tool off),
      "jobs": {"confirmed_cents", "confirmed_stages", "amounts_dont_match"} | null
    }
  Cancelled / rejected / expired orders never count.
  No audit event (read-only, own data). No names, phones or addresses in
  the answer.
