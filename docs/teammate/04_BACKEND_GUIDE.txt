---------------------------------------------------------------------------

3. ROUTES
---------------------------------------------------------------------------

    from src.api import api_bp
    from src.core.decorators import auth_required, current_user
    from src.core.responses import success_response
    from src.shared.rate_limit.limiter import limiter

    @api_bp.post("/me/credit-book/customer-debts")
    @limiter.limit("60 per minute")
    @auth_required(dashboard="informal_business")
    def add_customer_debt():
        data = load(NewDebtSchema(), request.get_json(silent=True))
        entry = credit_book_service.add_debt(current_user(), data)
        return success_response({"entry": credit_book_service.view(entry)}, status_code=201)

  - URLs under /me/... : always the signed-in trader's own data.
  - Every route: @auth_required + a rate limit.
  - Answers use success_response / error_response (the envelope the app
    expects: {success, message, data, code}).
  - Errors: raise AppError / ValidationError / NotFoundError from
    src.core.exceptions with a stable `code` the app can switch on.


4. MIGRATIONS
---------------------------------------------------------------------------

    flask --app app db migrate -m "credit book"
    -> rename the file to the next number: 00NN_credit_book.py and set
       revision = '00NN_credit_book' (look at the newest file in
       migrations/versions/ for the current number; tell Mandla which
       number you took so two PRs don't collide)
    flask --app app db upgrade
    flask --app app db check        -> "No new upgrade operations detected."
  Read the generated file before committing. Check constraints for every
  choice column (see business_profile model).
