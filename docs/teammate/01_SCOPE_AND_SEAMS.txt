3. THE SEAMS (where your tools meet Mandla's work)
---------------------------------------------------------------------------

  a) WHO IS SIGNED IN
       Frontend: useSession() from features/auth/session/SessionProvider
         -> profile (businessName, businessType, tools, ...)
       Backend:  @auth_required(dashboard="informal_business") and
         current_user() from src.core.decorators. That's all you need.

  b) WHICH TOOLS ARE ON
       profile.tools = { creditBook, orderStock, myRecord, jobs }
       Turning a tool on/off: useSession().setTool(key, on). It already
       saves to the server (business profile sync). "My record" can't be
       switched off. Adding a NEW tool key (e.g. dailyTally) needs a
       change in both constants/businessTypes.ts and the backend's
       business_profile constants: ask Mandla (feedback/).

  c) "I OWE SUPPLIERS" (credit book, second tab)
       Some of those debts will come from real ORDERS (supplier gave
       stock on credit). Orders are Mandla's. For now:
         - the trader can ADD a supplier debt by hand (your data), and
         - leave a clearly marked hook: suppliersOwedFromOrders() in your
           api, returning [] in the mock. Mandla fills it when orders
           exist. Show both in one list, labelled by source.

  d) MY RECORD
       The record counts things confirmed by both sides. Your tools feed
       it: repayments recorded (credit book), stages signed off by the
       client (jobs). Orders + cash handshakes (Mandla) feed it too. Build
       the screen and the share link over an interface like:
         recordApi.summary() -> { monthsTrading, confirmedByBoth,
                                   recordedByYou, entries: [...] }
       where entries have a `source` ("credit_book" | "job" | "order").
       Mock the "order" ones; Mandla wires them.

  e) PHOTOS (jobs: stage photos)
       Use the media module; don't write your own Cloudinary code.
       Folder: folders.informal_trader_job_folder(user.id, job.id).
       How: README "How to use media" + the profile photo as the worked
       example (business_profile/services/profile_image_service.py).
       Stage photos are CAMERA ONLY (never the gallery) -- file 07.

  f) NOTIFICATIONS / HOME NUMBERS
       Home shows "you owe suppliers" (from c) and "cash taken today"
       (roadmap/tally). Use your own api functions; if a number comes
       from orders, mock it and mark it.

  g) WHATSAPP
       Receipts and reminders open WhatsApp with a pre-filled message
       (a wa.me link), sent BY THE TRADER from their own phone. No
       WhatsApp API, no server sending messages this weekend (file 10).
